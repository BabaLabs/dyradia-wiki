## Description & Function

### Lieutenant 3 (Optional, Late): **The Continuity Engine**

**Role:** Not a person — a system  
**What It Is**  
A massive stabilization array designed to:

- Permanently suppress planar fluctuation
    
- Anchor reality in key regions
    
- Eliminate the possibility of Awoken emergence
    

**Why It Matters**  
Destroying it:

- Saves possibility
    
- Risks catastrophic instability
    

Leaving it intact:

- Preserves lives
    
- Erases futures
    

This is where Seraphel stops being abstract.
