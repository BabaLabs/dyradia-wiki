# The Still Point

## Territory Placement

**The Still Point** (late)

- **Where:** a location that feels “too stable” (could be near a repaired Interstice gate, or a sanctuary town)
    
- **Reach:** the world gets quieter around it—magic and emotion smooth out
    

---

# 2 DM-Only: “If the Party Does Nothing” Drift (3–6 sessions)

Not a railroad—just how pressure naturally builds.

- **Stasis:** treaty compliance spreads → border task forces normalize → “unlicensed” becomes synonymous with “dangerous”
    
- **Renewal:** miracle hotspots multiply → one high-profile catastrophe creates polarized public opinion
    
- **Convergence:** one region becomes unnervingly harmonious → leaders start delegating decisions to a stabilizer “because it works”

## Description & Function

### Lieutenant 3 (Late): **The Still Point**

**Role:** The Convergence’s heart  
**What It Is**  
A location where:

- Magic stabilizes perfectly
    
- Time feels smooth
    
- Emotion dulls slightly
    

This is where the party realizes:

> “The world is becoming quiet.”
